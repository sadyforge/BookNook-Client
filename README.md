# 📚 BookNook – Online Library Management System

BookNook is an online library management platform where users can explore books, manage their personal book collections, and borrow or return books easily. It provides a simple and user-friendly experience for managing library activities.

## ✨ Key Features

- 📖 **Browse Books:** Explore and discover books from the available collection.
- 🔍 **Book Details:** View detailed information about each book.
- 🔐 **Authentication:** Secure user registration and login system.
- ➕ **Add & Manage Books:** Authenticated users can add, update, and delete books.
- 📚 **Borrow Books:** Users can borrow available books from the library.
- ↩️ **Return Books:** Manage borrowed books and return them easily.
- 👤 **Personal Library:** View and manage your borrowed books.
- 📱 **Responsive Design:** Optimized for desktop, tablet, and mobile devices.

## 🛠️ Technologies Used

**Frontend:**
- Next.js
- React
- TypeScript
- Tailwind CSS
- DaisyUI
- Swiper.js

**Backend:**
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Better Auth

## 🚀 Getting Started

1. Clone the repository.
2. Install dependencies using `npm install` or `pnpm install`.
3. Configure the required environment variables.
4. Start the development server.
5. Open the application in your browser.
